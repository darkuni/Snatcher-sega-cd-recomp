# Third-party code

## Musashi 68000 emulator (src/third_party/musashi)
Copyright 1998-2001 Karl Stenerud. MIT licence - see `src/third_party/musashi/LICENSE.txt`.
Used as the fallback interpreter for guest code the recompiler has not seen, and as the reference
in `tools/difftest`. `m68kops.c/.h` are generated by Musashi's `m68kmake` from `m68k_in.c`.

## SoftFloat (src/third_party/musashi/softfloat)
Written by John R. Hauser, as packaged with MAME and Musashi; see the notice at the top of
`softfloat.c` (free use with attribution). Only built because Musashi's FPU code includes it.
